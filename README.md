# Hire an Agent

Describe a repetitive job, watch an AI agent do it on your own example, and get its CV.

A free tool by [Varahion](https://github.com/varahion). Write a one-line "job ad" for a task you repeat every week, paste one real example, and interview the candidate: it works on your example live, answers your questions, and hands you a shareable CV card.

**Status:** in development.

## Run locally

Requires Node 24.

```bash
npm install
cp .env.example .env.local   # fill in the values
npm run dev
```

## Privacy

We use your example only to run this interview. It isn't saved by this tool or shown to anyone else, and the interview closes after an hour.
